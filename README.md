# A NIGHTMARE

Horror game developed in Python using the Raycasting technique.

## Objective
Collect all files scattered throughout the map to gain time and advance to the next level.

*   **Language:** Python 3
*   **Graphics Library:** Pygame (SDL)
*   **Technique:** Raycasting (Pseudo-3D engine inspired by Wolfenstein 3D)
*   **Optimization:** Texture caching system and pre-calculated trigonometric tables.
